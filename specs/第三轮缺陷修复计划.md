fn is_chunked(header_str: &str) -> bool {
    header_str.lines().any(|line| {
        let l = line.to_lowercase();
        l.starts_with("transfer-encoding:") && l.contains("chunked")
    })
}

fn is_connection_close(header_str: &str) -> bool {
    header_str.lines().any(|line| {
        let l = line.to_lowercase();
        l.starts_with("connection:") && l.split(':').nth(1).map(|v| v.trim() == "close").unwrap_or(false)
    })
}
```

fn parse_content_length(header_str: &str) -> Option<usize> {
    for line in header_str.lines() {
        let l = line.to_lowercase();
        if l.starts_with("content-length:") {
            let val = line.splitn(2, ':').nth(1)?;
            return val.trim().parse().ok();
        }
    }
    None
}
```

### T4: chunked body_buf 改为滑窗（仅保留最后 64KB）

两个函数 `stream_http_response` 和 `stream_response_simple`：
- 去掉 `body_buf: Vec<u8>` 的无界 extend
- 改为只保留最近 64KB 的滑窗 buffer
- 每次读取后检查滑窗中是否包含 `0\r\n\r\n`

实现：
```rust
const CHUNK_TAIL_LEN: usize = 64 * 1024;
// ...
let mut tail = Vec::with_capacity(CHUNK_TAIL_LEN);
// 初始化 tail 为 body_start
if is_chunked {
    tail.extend_from_slice(body_start);
}
// loop 内：
if is_chunked {
    tail.extend_from_slice(&tmp[..n]);
    if tail.len() > CHUNK_TAIL_LEN {
        let drain = tail.len() - CHUNK_TAIL_LEN;
        tail.drain(..drain);
    }
    if find_chunked_end(&tail, 0).is_some() {
        break;
    }
}
```

注意：`find_chunked_end` 需要解析完整的 chunk 结构，滑窗可能在 chunk 边界处截断。但 `0\r\n\r\n` 终止标记最多只有 5 字节（`0\r\n\r\n`），滑窗 64KB 足够覆盖任何 chunk 的终止。更安全的方案：直接搜索 `b"0\r\n\r\n"` 子串——但需要确保是 chunk size 行而非 chunk data 的一部分。

**更安全的方案**：直接搜索 `b"\r\n0\r\n\r\n"` 子串（chunk 边界 + terminator）。这比 `find_chunked_end` 的解析逻辑更鲁棒，且不需要完整 buffer。

```rust
// chunked 终止检测：搜索 "\r\n0\r\n\r\n" 或 body 开头的 "0\r\n\r\n"
fn find_chunked_terminator(buf: &[u8]) -> bool {
    // 标准终止：[CR LF] 0 [CR LF] [CR LF]
    // 如果 body 以 "0\r\n\r\n" 开头（只有一个 chunk size=0）
    if buf.starts_with(b"0\r\n\r\n") {
        return true;
    }
    buf.windows(5).any(|w| w == b"\r\n0\r\n")
        && buf.windows(7).any(|w| w == b"\r\n0\r\n\r\n")
}
```

简化：直接搜索 `b"\r\n0\r\n\r\n"` 或 `b"0\r\n\r\n"`(开头):
```rust
fn has_chunked_terminator(buf: &[u8]) -> bool {
    buf.starts_with(b"0\r\n\r\n") || buf.windows(7).any(|w| w == b"\r\n0\r\n\r\n")
}
```

这样只需要 7 字节的滑窗就够了，但为安全起见用 64KB。
